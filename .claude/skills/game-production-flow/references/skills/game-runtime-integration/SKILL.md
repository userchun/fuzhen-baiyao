# 游戏运行时接入
确认真正运行的目录、端口、构建和目标设备。网页原型、引擎工程和微信构建分别验收。
使用现有引擎与工程规范；必要时读取引擎官方文档，不能凭另一个引擎的 API 实现。

## 资源契约
按 ../../templates/asset-record.json 记录 ID、角色/阶段/品质、状态、路径、来源、提示词、尺寸、透明度、帧矩形、锚点、发射点和使用位置。
源图与运行素材分开，保留版本，不以覆盖旧图掩盖未完成变体。依据实际 PNG 尺寸计算裁切，不假定生成图为 1024/1280。
检查帧间越界、半透明雾底、邻帧露出、脚底跳动、武器误配和投射物重复。SVG 仅有 viewBox 不足以避免留白区露出相邻帧；使用明确 clipPath 或按帧绘制。

## 接入顺序
先接配置与状态，再接 UI 事件、素材映射、战斗时序与音效。生成图不算接入完成；图片在列表存在也不代表战斗选用了它。
旧装备 ID、已有资源和存档保持兼容。选取有效品质与阶段，不能只读初始模型品质。移动、攻击、受击、胜负的优先级明确，避免受击动作吞掉发射动作。
加载失败可重试；只释放不再使用的资源；切后台暂停并保存；减少动态模式有对应表现。
编辑后运行项目实际 lint fix、语法检查和必要测试；缺少配置时如实记录。完成后用实际页面操作证明，不通过注入内部状态冒充正常玩法。
