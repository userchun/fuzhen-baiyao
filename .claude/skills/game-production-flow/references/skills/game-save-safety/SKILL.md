# 存档与永久资源
先定义资产不变量：所有权、余额、角色/武器/伙伴等级、已领取奖励、未完成对局。记录旧字段来源和迁移映射。
复杂不兼容演进使用独立存储世代，旧源只读保留。成长档和活跃对局都需要隔离，不能只改其中一个键。
迁移顺序：读取并验证旧源→保留原始副本→写新档→回读验证→标记完成。新档损坏优先有效备份；不自动重置、不把缺失新字段解释为资产归零。
旧页变化保存冲突证据并暂停经济写入。不得默认合并货币或重放不确定交易。
操作使用唯一编号、预期版本和原子持久化边界；同一结算重复提交无新增收益。写失败不能先更新 UI 内存并显示成功。
战斗奖励归属绑定开局快照；领取时奖励按已确认规则绑定当前选择。恢复旧对局有明确默认值。
测试：旧档迁移、旧页晚写、复制失败重试、双标签竞争、损坏回退、重复结算、恢复后实际继续战斗。测试数据使用独立 origin/存储，不能覆写用户档案。
浏览器工具只通过可见页面进行操作；需要测试夹具时建立明确独立测试页面，标注其证明范围。
