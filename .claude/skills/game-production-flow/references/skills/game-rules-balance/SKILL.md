# 规则与数值
读取当前正式配置和用户确认记录；提案用独立文件，未经确认不替换正式经济。
输出规则表：触发条件、目标、伤害/控制、CD、范围、叠加/覆盖、上限、解锁、获取、消耗。
区分角色固有技能、局内强化、局外等级、稀有度、进化形态；逐项定义影响哪些数值。

验证至少覆盖低/中/高成长、不同职业/伙伴、目标章节、合理随机种子与极端配置。先断言使用了正确章节、装备、等级和解锁条件，防止测试悄悄回退到默认配置。
记录版本、种子、选卡策略、首次释放时间、胜负、剩余生命、时长、技能贡献、资源产消；配对试验说明是否真正共用同一随机序列。
检查无限控制、护盾叠加、永久资源刷取、首次奖励、重复结算与付费/免费入口边界。
模拟证明规则表现，不证明真人趣味。保留弱势组合和不确定性；不要只报告平均胜率或为了全绿削弱全部关卡。
表格和图表优先于大段叙述；精确参数存 JSON，并在接入后复跑正式引擎验证。
