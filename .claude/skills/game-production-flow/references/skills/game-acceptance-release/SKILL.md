# 验收与交付
使用 ../../templates/acceptance.md，分别记录以下证据，不能互相代替：
1. 逻辑/资源检查：核心规则、有效配置、图集边界、文件引用。
2. 模拟：多配置胜负、经济和技能表现。
3. 浏览器正常流程：主页→选择→开战→局内成长→胜负→奖励→局外成长→刷新回读。
4. 隔离场景：失败/恢复/极端状态的特定路径，明确不代表整局通关。
5. 视觉：批准设计与运行截图对照；检查所有关键状态、裁切、图标含义、品质和进化层级。
6. 真机：触控、刘海/手势区、横竖屏策略、音频解锁、切后台、长局、加载、内存和帧率。桌面视口模拟不能称真机通过。

性能使用 web-perf 的可用工具；网页指标与游戏帧率/内存分开记录。没有真实测量时只报告文件大小或理论估算。

交付清单包括源码/版本、启动说明、资源索引、当前规则、迁移说明、测试证据和未完成/延期项。逐文件哈希核对运行源、导出目录与 ZIP；先生成临时包验证后替换。不得把校验通过说成发布完成。
只在全部范围的验收项有证据时标完成；功能可执行但未验收，状态应为待验收。上架、签名、账号、广告和付款保持用户控制。
