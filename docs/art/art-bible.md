## 1. 视觉总则

**一句话**：暗黑西游味的志怪世界。大头短身但造型凶狠的妖怪，在青蓝妖气笼罩的荒村里，被小道士用金色符咒打退。

**第一原则：样板的画风，割草游戏的可读性。** 风格样板是一张海报式的整图，正式素材要拆开来做，并且做得比样板更"干净"。

### 从样板里保留什么
- **厚涂**，体积感强，岩石、符纸、火焰、砖墙的材质都画得精细。
- **强烈的冷暖对比**：环境是青蓝色的妖气和夜色，角色和特效是朱红、金、黑。
- **轮廓光**：每个角色外圈都有一道浅色或五行色的轮廓光，把它从暗背景里分出来。
- **造型狰狞而不可爱**：獠牙、怒目、吐舌、夸张的头冠和法器。比例是大头，头身比约 1:2.5。

### 改掉样板的哪些缺点
| 样板的问题 | 正式素材的做法 |
|---|---|
| 背景太满太花 | 背景细节减半，路中间 60% 的宽度保持干净；房屋和杂物只放在两侧 |
| 妖怪朝向和大小不一 | 统一画成正面朝下、向镜头走来；同种怪大小一致 |
| 道士太小、不够 Q | 主角头身比约 1:2，显示尺寸要比小怪大 |
| 整体偏暗 | 路面提亮成中灰褐色，比两侧明显亮；角色比背景更亮、饱和度更高 |
| 图里有字（还是乱码） | 素材里一律不画文字，文字由游戏显示 |
| 整张图画在一起 | 背景、城墙、角色、特效、UI 分开出图 |

### 支撑原则

**1. 色即五行**
- 金 #F5D76E、木 #5FBF6A、水 #5AB4F0、火 #F06A4A、土 #B08A55 是全局唯一的语义色。
- 每只妖怪用一个五行主色，轮廓光也用这个色相。
- 背景的妖气只用**青蓝色**，不能用到五行里的水蓝。可以偏青绿灰，饱和度要低于水蓝。

**2. 剪影为骨，字印为识**
- 只看轮廓，加上胸口封印区的位置，就要能认出是哪种妖怪。
- 胸口留一块圆形空区，运行时在那里叠汉字。贴图里不要画字。
- 按手机上实际显示的 40–60px 来检验。

**3. 地暗路亮，妖怪最亮**
- 两侧的房屋和树最暗，路面中等亮度，妖怪、符咒和特效最亮。

### 明确禁止
- 照片写实、3D 渲染质感。
- 可爱萌系、日系美少女、扁平矢量贴纸。
- 素材里出现文字、水印、乱码。
- 照搬任何现成游戏的角色和画面。

## 2. 视角与比例

- **视角**：高俯视，大约 65°。主角背对镜头，妖怪正面朝下走向城墙。
- **比例**：主角头身比约 1:2；小怪约 1:2–1:2.5；Boss 体型约为小怪的 4 倍。
- **画法**：厚涂加轮廓光，不要粗黑描边。轮廓靠明暗对比和轮廓光来区分。

## 3. 造型

| 妖怪 | 五行 | 造型要点（参考样板） |
|---|---|---|
| 纸人 | 木 | 撕裂纸边的绿色纸人，身上贴一张红字符纸，枯瘦的爪子，青绿色妖火 |
| 跳尸 | 土 | 戴清朝官帽、额头贴黄符，青灰色的脸，吐舌头，双臂平伸 |
| 狐火 | 火 | 白毛红纹的狐狸，尾巴烧成火焰，眼睛发红 |
| 灯笼鬼 | 火·精英 | 红色方灯笼的身体，独眼，獠牙大嘴，舌头垂下，挂着铁链 |
| 黑山老妖 | 土·Boss | 岩石山形的巨妖，头顶尖峰，琥珀色怒目，身上有熔岩裂纹 |
| 小道士 | 主角 | 背对镜头，黑白道袍，太极纹，金色发冠，长发，黄色飘带，举着燃金光的符纸 |

## 4. 环境

- **荒村**：夜，满月。路面是中灰褐色的土路，有车辙；两侧是残破的青瓦屋顶、枯树、倒塌的篱笆、红灯笼，飘着青蓝色的妖气。
- **城墙**：青黑色的砖砌垛口，中间垂着一道朱红符纸幡，有铁链。
- **道具密度**：只放在两侧。路中间只能有小石子和车辙。

## 5. 特效

- **金光符**：金色光矛，带一圈符纸碎光；命中时是金色星芒。
- **烈焰符**：橙红色火球，爆炸时有碎石和火星，样板中间那团爆炸就是目标效果。
- **其他符咒**：都用"厚涂实体加发光"的画法，不能只有光晕。

## 6. UI / HUD

- **整体**：黑铁、金边、朱红，和样板底部的血条一致：两端是兽首，中间是太极徽。
- **结界血条**：暗朱砂色 #9B3D2E。
- **Boss 条**：左上角，带 Boss 头像框和金边。
- **击杀数**：右上角，配骷髅图标。
- **选卡**：深色底，金边，朱红挂穗。卡面中间是黄符纸大图。
- **飘字层级**：克制金 #FFD700 加"!"，普通白，被克灰。

### 界面配色规则（2026-10-30，样板 `docs/art/ref/ui_mainmenu_v8.png`）

所有界面（主界面、养成、符咒、记录、结算、设置）都按这四条：

1. **背景低饱和、压暗**：界面背景用深灰蓝，饱和度比战斗场景低，远景带雾气做空气透视；不出现大面积亮青或大面积红。
2. **亮色只留给焦点**：一个画面最多两个高亮点，一般是"主角或主视觉"和"主按钮"。红眼、灯火、装饰都压暗。
3. **界面框收敛**：深色半透明底加细金边；厚重雕花框只用在标题匾额这一处。按钮不加火焰等特效装饰，动感交给程序做呼吸光。
4. **字色只用两种**：标题和主按钮用亮金 #FFD66E，其余文字用米白 #E8DEC6，统一加深色描边。文字一律由程序显示。

### Boss 与小怪的动作和机制（完全按同类割草游戏的结构）

参照《向僵尸开炮》43 个 Boss、217 个小怪的配置，动作套数、帧数和攻城方式都按它来。**只照搬结构，造型一律按本文件的风格自己设计，不临摹它的任何角色。**

**小怪（逐帧，单帧 256）**

| 动作 | 帧数 | 循环 | 用在哪 |
|---|---|---|---|
| idle 待机 | 6 | 循环 | 刚生成、被冻住、被击退后的停顿 |
| move 行走 | 12 | 循环 | 走向城墙 |
| attack 攻击 | 10 | 循环 | 走到墙下后停住，持续攻击城墙；在第 6 帧结算一次伤害 |
| death 死亡 | 6 | 一次 | 被打死 |
| hurt 受击 | 1 | — | 受击时切到这一帧并闪白，0.1 秒后切回 |

**Boss（逐帧，单帧 384）**

| 动作 | 帧数 | 循环 | 用在哪 |
|---|---|---|---|
| appear 出场 | 12 | 一次 | 登场，配合停顿、震屏和 Boss 血条入场 |
| idle 待机 | 12 | 循环 | 放技能前后的停顿 |
| move 行走 | 12 | 循环 | 走向城墙 |
| skill1 技能一 | 12 | 一次 | 招牌技能，和机制绑定 |
| skill2 技能二 | 16 | 一次 | 第二技能，触发条件由每个 Boss 自己定（黑山老妖半血后、白骨夫人每次换相时），见 `docs/gameplay-design.md` 2.4 节 |
| death 死亡 | 12 | 一次 | 被打死 |

受击和小怪一样，代码闪白加顿帧，不出图。

**攻城方式**：小怪和 Boss 走到墙下停住攻城（小怪循环播 attack，Boss 播 idle 加周期 skill），规则和数值见 `docs/gameplay-design.md` 2.3 节。

**一个造型出两三档**：同一造型换五行色、加头饰或法器，做成升级版，数值往上调。

**靠机制区分怪**：已有快（狐火）、跳（跳尸）、分裂（灯笼鬼）、护甲（铜甲尸）、潜水（水鬼）。新怪从自爆、给友军加盾、召唤、飞行里挑；剪影要一眼看出机制。

### 参考拆解：《向僵尸开炮》整体美术

2026-10-28 浏览全部逆向素材后的结论。素材只当拆解参考：学比例、节奏和动作结构，**图不进游戏，造型不照描**，自己的素材仍按 `style_target.png` 出。

本地预览页：`~/Documents/Codex/2026-10-27/qu-w/outputs/apk-reverse/完整素材/Boss动画/Boss全部动作预览.html`，在 `完整素材/` 目录下起一个 http 服务即可打开。页面有 28 个标签页，包括 Boss、小怪、角色、机甲、核心、UI 动画、背景、特效等。

| 观察 | 我们怎么用 |
|---|---|
| Boss、小怪、角色的头身比和描边粗细统一，同屏不打架 | 所有角色共用一套头身比和描边粗细（以已定稿的主角为基准）；新素材出图前先和已定稿素材并排对比 |
| 动作数量克制：小怪 3~4 个动作，Boss 6 个左右 | 维持上面两张表，不再加动作；打击感靠特效、闪白、顿帧和飘字补 |
| 打击感主要来自特效：命中、爆炸、死亡散落都有专门特效 | 每个符咒配齐"飞行、命中、爆开"三段；死亡统一用五行色散落特效，不用每只怪单独画 |
| UI 本身也在动：宝箱、奖杯、活动入口共有约 300 个动画 | 关键 UI 加小动画：选卡翻牌、结算宝箱、Boss 血条入场；先用代码做缩放和发光，不出序列图 |
| 同一造型做多档：靠换色和加配件拉出升级版 | 同"一个造型出两三档"，按五行换色 |
| 角色、Boss、机甲、UI 用骨骼动画，只有小怪用逐帧 | 我们现在全部用逐帧序列图。等动作或角色多到出图成本扛不住时，再评估 Boss 和主角改用骨骼动画 |
| 城墙每面固定三张：idle 完好、hurt1 轻损、hurt2 重损，均为 1024×256 | **优先做**。城墙出三档：血量高于 60% 用完好图，30%~60% 用轻损，低于 30% 用重损；三张构图和尺寸一致，只加裂纹、缺口和焦痕，切换时配一次震屏 |
| 伤害数字是一张 1024×64 的数字图（0~9 和符号排成一条），每种语言各一张 | **优先做**。飘字改用金色描边的数字图：克制、普通、被克各一条，颜色沿用第 6 节的飘字层级；"!" 和"+"也画进同一条 |
| 特效序列图多用小网格：2×2、4×4、3×3 居多，单张 256~512 | 特效不再统一 4×2：小火花和命中用 2×2（4 帧），常规弹道用 4×2，大爆炸和 Boss 技能用 4×4 |
| 背景几乎都是 512×1024 的竖条切片，一个场景由几段拼成 | 多关之后背景改为分段切片：顶、中、底三段，中段可复用和循环；第一关先保持整张 1024×1536 |
| 图标量很大：UI 图标约 5500 张，战斗界面另有约 400 张 | 符咒、五行、被动技能的图标先定统一规范：同一底框、同一尺寸、同一描边粗细，新图标都按规范出 |

**战斗 UI**（看的是战斗界面图集 `UIRaw_Battle` 和通用组件 `commonnew`）

| 观察 | 我们怎么用 |
|---|---|
| 选技能卡是竖长卡，用边框颜色分品质：白、蓝、金红三档，卡面上半部是大图标，下半部写字 | 选卡沿用"黄符纸大图"，再加品质边框：普通是素纸，稀有是青铜边，传说是朱红金边。一眼就能分出档次，不用读字 |
| Boss 来袭有专门的警示元素：斜纹警戒条、红色横幅、骷髅图标 | Boss 登场时加一条朱红横幅，配黑金斜纹边，中间写妖名，和 appear 动作同时播放 |
| 箭头和斜切色条很多，用来做进度、方向提示和标题底 | 波次进度和"下一波"提示用斜切色条，加箭头指向城墙方向 |
| 结算宝箱分很多档（约 9 档），越高档越华丽 | 结算按评价给 3 档宝箱：木、铜、金，开箱时用缩放加发光动画 |
| 特效和 UI 底纹大量使用网点（半调）纹理，带一点漫画感 | 我们的冲击波、爆点可以叠一层朱红网点纹理，增强冲击感；需要先出图验证是否适合暗黑国风 |
| 按钮、底板、血条都是可拉伸的通用组件，同一套组件复用到所有界面 | UI 先做一套通用组件：按钮（确认、取消、主操作）、底板、进度条、标签，所有界面都用这套拼 |

**战斗城墙**（看的是 `sprite_battlewall`，约 30 套主题皮肤）

| 观察 | 我们怎么用 |
|---|---|
| 城墙是俯视的宽平台，主角站在平台上，不是一堵竖着的墙 | 我们的城墙也画成能站人的垛口走道，和主角"站在垛口后走道"的定位一致 |
| 结构固定：左右对称，两端是立柱或塔楼，中间有一个徽记，平台面是大块平整区域 | 城墙统一成"两端镇兽石柱 + 中间太极或符印徽记 + 平整石板走道"，走道上不画杂物，免得和主角、特效抢视线 |
| 30 套皮肤只换主题（科技、国风、水面、樱花、雪地、星空），轮廓和尺寸不变 | 换皮只换材质、颜色和徽记，轮廓尺寸固定；以后每关或每种五行出一套：金铜、木藤、水冰、火砖、土石 |
| 龙、花等大装饰单独成一层，叠在城墙上 | 城墙和装饰分开出图：先出干净的墙体，石兽、旗幡、符纸另出一层，方便复用和做动画 |
| 每套都有大小两个版本 | 战斗用大图，选关或城墙升级界面用缩略图，同一张图缩小即可，不另画 |
