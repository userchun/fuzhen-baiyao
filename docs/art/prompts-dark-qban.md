# 符镇百妖 · 国风剪纸 Q 版出图提示词包

> 2026-10-30 风格改为国风剪纸 Q 版，文件名沿用旧名。下面各素材的【主体】里仍有暗黑版的写法（如"冷青蓝月光""厚涂材质"），出图时以风格锁为准，用到哪条就顺手改成剪纸写法。

风格依据：`docs/art/art-bible.md`。风格样板：`docs/art/ref/style_target.png`。

## 使用规则（每条都要遵守）

1. **参考图**：每次出图都附上风格样板 `style_target.png`。出同一个角色的序列图时，还要附上这个角色的定稿单张。
2. **拼法**：最终提示词 = 【风格锁】+ 该素材的【主体】+【构图】+【约束】。最后附上【负面词】：模型支持负面词就填进负面词栏，不支持就把它接在提示词末尾。
3. **一次一张**：先出单张定稿，确认后再出序列图。
4. **不要文字**：所有素材里都不能有字。凡是需要文字的地方，都由游戏程序显示。
5. **背景**：角色、城墙、UI 一律用 **纯绿 #00FF00 背景**，方便抠图；特效一律用 **纯黑背景**，靠亮度转成透明。

## 风格锁（每条提示词开头都加）

```
国风剪纸皮影风格Q版手游美术，风格与参考图一致：中国传统剪纸和皮影戏偶，大块平涂色块，只有一两层明暗，表面带淡淡的宣纸纤维纹理；干净略粗的剪纸外轮廓，边缘是剪刀剪出的利落折角，局部用镂空云纹、回纹装饰；前后层之间有纸片叠贴的浅投影；配色克制：米白宣纸、朱红、墨黑、描金，再加角色自己的五行色；Q版大头比例约1:2，可爱比例配凶狠神情（怒目、獠牙、利爪）；高俯视视角约65度；只学参考图的画风，不照搬参考图的构图。
```

```
文字，字母，数字，乱码，符纸上的汉字，水印，签名，logo，边框，UI界面（除非要求），厚涂，照片写实，3D渲染，写实材质，日系美少女，扁平矢量图标，细碎飘散的纸屑和烟雾，大片光晕，侧视角，模糊，低分辨率，画面过暗，多余角色
```
