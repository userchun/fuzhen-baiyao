## 0. 定位（原简纲）

**一句话**：守在城墙上画符镇妖，用五行相克和符咒相生，挡住一波比一波凶的百鬼夜行。

**给谁玩**：喜欢割草肉鸽的竖屏手游玩家，想要一局 3 分钟、越打越爽的构筑成长感。

**核心循环**：拖动底部移动、按住战场瞄准连发 → 击杀得灵气、升级三选一 → 两个相生符咒到 3 级触发合击 → 击败 Boss 过关 → 结算拿铜钱、符纸 → 局外升级 → 再打下一关。

**参考**：吸血鬼幸存者 + 塔防守墙，保留"自动攻击 + 三选一升级"，去掉自由移动地图，局外成长只做轻量加成。画面可读性参考休闲竖屏俯视射击，画风气质参考暗黑西游卡牌，都不照搬。

**美术方向**：暗黑国风 Q 版，详见 `docs/art/art-bible.md`。

**不做**：
- 会改变局内玩法的局外系统（法器、角色、皮肤）、道行等级、护符、符咒分支
- 付费货币、体力、联网、排行榜、云存档
- 第三关及以后（方向见第 5 节，暂不开发）

## 1. 一局的流程

菜单 → 选关 → 战斗（约 160 秒 + Boss）→ 结算 → 领奖 → 回到局外养成

**胜负规则**：击败本关最终 Boss 即胜利，不要求清完杂兵；Boss 开始播死亡动作时就停止刷怪。城墙血量归零即失败。🛠 补充两条：
- 同一帧里城墙归零和 Boss 死亡同时发生，算失败。
- 🧪 战斗最长 240 秒（暂停、选卡、切后台不计时），超时算失败，210 秒时提前提示。

| 结算发奖、局外养成界面 | 🛠 | 见第 3、4 节 |

### 1.1 暂停与设置 🛠

- 局内右上角放暂停按钮；切到后台时自动暂停。选卡时游戏本来就是暂停的。
- 暂停菜单有四项：继续、音乐开关、音效开关、退出本局。
- 退出本局按失败结算，正常发失败铜钱（按存活时间算，不会被拿来刷奖励）；不发首通奖励，也不开精英铜箱。
- 主菜单的"设置"有四项：音乐开关、音效开关、震屏开关、清除存档（要二次确认）。设置项存进存档的 `settings` 字段。

### 3.2.1 一次性记账 🛠

- 每局开局生成唯一的 `runId`。结算时把铜钱、符纸、首通记录和 `runId` 一次写进存档。
- 已经记过账的 `runId` 不会再发奖：重开结算界面、结束事件触发两次、保存重试，都不会重复加钱。
- 保存失败时保留待提交的结算结果，提交成功前不能开下一局。这只保证本地逻辑一致，不当作防作弊。

## 4. 局外养成 🛠

最早的简纲写"不做局外养成"，2026-10-30 改为做一套轻量版：只加基础属性，不改变局内构筑的玩法。

### 4.1 城墙与道士属性 🧪

各项都是 5 级封顶，每级价格是上一级的 1.3 倍。第三关上线后再提高等级上限。

| 项 | 每级效果 | 上限 | 价格（1→5 级） | 升满合计 |
|---|---|---|---|---|
| 城墙加固 | 城墙血量 +6 | 5 级 | 50 / 65 / 85 / 110 / 143 | 453 |
| 符笔 | 镇妖符伤害 +4% | 5 级 | 60 / 78 / 101 / 132 / 171 | 542 |
| 聚灵 | 灵气获取 +4% | 5 级 | 80 / 104 / 135 / 176 / 228 | 723 |
| 开坛 | 开局多选卡 1 次 | 1 级 | 400 | 400 |

开坛只有 1 级：第二关本身就送 2 次开局选卡，叠加太多会让开局完全没有压力。

**加成上限原则**：永久加成压小，局外的乐趣主要是"有进展、更有容错"，不是"数值碾压"。全部升满后：城墙 130、镇妖符伤害 +20%、灵气 +20%、开局多 1 次选卡、每种符咒伤害 +15%。普通难度零养成也必须能通关。

### 4.2 符咒星级 🧪

- 六种符咒开局全部可用，不做解锁。两组合击从第一局就都能凑出来，核心构筑不被养成卡住。
- 每种符咒可升 3 星，每星基础伤害 +5%，价格依次是 3、6、10 符纸（每种 19，六种合计 114）。星级只加数值，不改变符咒的效果。

### 4.3 存档

| 项 | 状态 |
|---|---|

### 4.4 界面与流程 🛠

**主菜单**：开始游戏、养成（新增）、设置。养成按钮右上角在"有可升级项"时显示红点。

**选关页**（已有，补充）：每关显示普通 / 困难两个按钮；困难难度在普通难度通关后才能点。每个按钮下方显示首通奖励，已领过的显示"已领"。

**结算页**（改造）：
1. 胜利 / 失败标题，存活时间、击杀数。
2. 奖励逐行滚动入账：通关铜钱 → 精英铜箱（逐个开箱，按档位换宝箱图）→ 首通奖励（有首通才显示）。
3. 底部显示累计铜钱和符纸。
4. 按钮：失败时为"去养成"（主按钮）和"再来一局"；胜利时为"下一关"（主按钮）和"去养成"。

**养成页**：
- 上方：铜钱、符纸余额。
- 第一个页签"道士"：四项属性做成竖排卡片，每张卡写名称、当前级 / 上限、当前效果 → 下一级效果、价格按钮。钱不够时价格变红、按钮置灰；满级显示"已满"。
- 第二个页签"符咒"：六种符咒做成 2×3 网格，显示星级；点开看每星效果并升星。
- 每次升级播一次盖印动画和音效，不弹确认框（升级不可撤销，但单次花费小）。

### 4.5 失败引导 🛠

失败结算时，按下面的顺序挑一条建议，显示在奖励区下方：

| 条件 | 建议文案 |
|---|---|
| 死于 Boss 战，Boss 剩余血量 < 30% | "差一点！升级符笔，伤害更高" |
| 死于 Boss 出场前 | "城墙撑不住？升级城墙加固" |
| 本局最高等级低于预期（🧪 第一关 < 8 级） | "灵气不够？升级聚灵" |
| 上面都不满足 | 推荐当前买得起、且最便宜的一项 |

钱不够时仍然显示建议，并写明还差多少铜钱，鼓励再打一局。

### 4.6 养成满级之后 🛠

现有内容下，养成大约 20 局升满。之后玩家的目标是：
- 困难难度首通（额外符纸奖励，以及选关页上的金色印章）。
- 每关最短通关时间，显示在选关页上，只记本地。
- 🔭 第三关上线时，同时提高属性上限到 8 级，并加入新的消耗。

### 4.7 新手引导 🛠

- 第一局结束后，回到菜单时，养成按钮高亮闪烁，旁边一句提示："用铜钱加固城墙"。
- 第一次进入养成页时，城墙加固卡片高亮，引导买下第 1 级（第一局最少也能拿到约 30 铜钱，不一定够；不够时提示改为"再打一局就够了"）。
- 引导只出现一次，完成后记 `flags.metaTutorialDone`。

## 6. 验收标准

### 6.1 现有功能（回归用）

- [ ] 两关都能从菜单一路打到结算，没有卡死和报错。
- [ ] 克制显示放大的彩色数字，被克显示缩小的灰色数字。
- [ ] 两组合击在条件达成时触发，有提示和音效。
- [ ] 通关第一关后，重开游戏能选第二关。

### 6.2 待实现功能（做完逐条验）

- [ ] 妖怪在墙下停住、播攻击、按间隔扣血；攻城位最多 8 个，满了的在后面排队，前面被打死后补位。
- [ ] 不管墙下堆了多少小怪，城墙每秒掉血都不超过 8（Boss 伤害另算）。
- [ ] 城墙血量到 60%、30% 时换破损图。
- [ ] 黑山老妖半血后会掷巨石，有预警，砸中扣血。
- [ ] 结算页显示铜钱、符纸、宝箱，数字和第 3 节一致；首通只发一次。
- [ ] 养成页能升级，价格正确，钱不够时按钮置灰。
- [ ] 养成效果在局内生效（城墙血量、伤害、灵气、开局选卡数）。
- [ ] 重复通关铜钱减半，困难难度奖励翻倍；精英必掉铜箱。
- [ ] 结算页奖励逐项入账，宝箱逐个打开；失败时显示一条升级建议，规则和 4.5 节一致。
- [ ] 主菜单养成红点只在"有买得起的升级"时出现。
- [ ] 选关页正确显示首通奖励和"已领"，困难难度在普通通关后才可选。
- [ ] 新手引导只出现一次；重启后不再出现。
- [ ] 符咒升星后，对应符咒在局内的伤害按 +5% / 星生效。
- [ ] 冻结、击退能取消还没命中的攻击；妖怪死后不再扣城墙血；缺 attack 图也能正常攻城。
- [ ] Boss 出场无敌；冻结最多僵直 0.3 秒，之后 2 秒免疫；技能有预警。
- [ ] 城墙归零和 Boss 死亡同一帧时判失败；战斗超过 240 秒判失败，210 秒有提示。
- [ ] 城墙上限变化后，回血、固元、血条都按新上限算。
- [ ] 双指同时移动和瞄准互不干扰；暂停或选卡恢复后不会自动继续射击。
- [ ] 城墙不高于 40% 时选卡固定出现回血；刷新卡后保底照常。
- [ ] 同一局结算只记一次账；保存失败时不丢结果、不能开下一局；存档损坏时从备份恢复。
- [ ] 白骨夫人在 66%、33% 血量时蓄力化骨，有明显预警；用克制当前相的伤害能打断，打断后眩晕 2 秒。
- [ ] 困难难度的四条规则都生效，奖励翻倍。
- [ ] 局内能暂停；切后台自动暂停；退出本局按失败结算，不发首通奖励。
- [ ] 设置的开关在重启后保留；清除存档要二次确认。
- [ ] 每局结束追加一条试玩记录，字段齐全，最多 50 条；长按版本号能复制出 JSON。
- [ ] 存档在重启后保留；旧存档（只有解锁进度）能平滑升级，不清空进度。

### 6.3 平衡目标（只有这一套，🧪）

| 情况 | 第一关通关率 | 第二关通关率 |
|---|---|---|
| 零养成 | 60–80% | 40–60% |
| 养成全满 | ≥ 90% | ≤ 90% |

`scripts/balance-sim` 模拟不了玩家手动瞄准的水平，跑出来的数字只用来比较两版数值哪个更难。定稿要靠真人试玩：至少 3 人各打 5 局，结果落在上表范围内才算过。

### 6.4 试玩记录 🛠

每局结束（含中途退出）在本地追加一条记录，存到 `fuzhen.runLog`，只保留最近 50 条：

| 字段 | 内容 |
|---|---|
| `time` | 结束时间 |
| `level`、`difficulty` | 关卡序号、普通 / 困难 |
| `result` | 胜利 / 失败 / 退出 |
| `survived` | 存活秒数 |
| `maxLevel` | 本局最高等级 |
| `picks` | 选卡顺序（符咒 / 心法 id + 级数） |
| `combos` | 触发了哪些合击 |
| `deathCause` | 失败时：Boss 战中 / Boss 出场前，以及当时 Boss 剩余血量比例 |
| `meta` | 当时的养成等级和符咒星级 |
| `reward` | 本局拿到的铜钱、符纸 |

在设置页长按版本号，可以把全部记录复制成 JSON，用来统计通关率和常见构筑。正式上架前去掉这个入口。

### 6.5 体验目标（试玩判断）

- 一局 3 分钟左右，最后 30 秒最爽。
- 新玩家第一次就能看懂相克，第三局前会主动凑合击。
- 输了也觉得"差一点"，愿意升一下养成再打。
