# 符镇百妖 · 主设计文档（总览）

> 本文是画布上的入口总览，只写定位、结构和导航，不复制规则和数值。
> 玩法规则唯一来源：`docs/gameplay-design.md`；数值以 `assets/scripts/config/GameConfig.ts` 为准；美术以 `docs/art/art-bible.md` 为准。冲突时以那几份为准，并回来改本文。

## 1. 一句话
守在结界后画符镇妖，用五行相克和符咒相生，挡住一波比一波凶的百鬼夜行。

- 平台：Cocos Creator 3.8.8，竖屏手机，一局约 3 分钟。
- 玩家：喜欢割草肉鸽、想要构筑成长感的竖屏手游玩家。
- 参考：割草类自动攻击 + 三选一升级，结合塔防守墙；不做自由移动地图。

## 2. 设计支柱
1. **守墙压力**：妖怪攻城有明确的伤害预算和攻城位，结界血量就是紧张感的来源（见 gameplay-design 第 2.3 节）。
2. **五行构筑**：六符各有属性，克制 ×1.5 / 被克 ×0.7；相生链决定合击与五行大招的强度（第 2.2、2.5 节）。
3. **轻量局外**：局外只加基础属性和符咒星级，不改变局内玩法（第 4 节）。

## 3. 核心循环
符咒全自动攻击，拖动屏幕左右走位 → 击杀得灵气 → 升级三选一（符咒 / 升级 / 心法，合计最多 4 种）→ 相生符咒到 3 级触发合击 → 击败 Boss 过关 → 结算铜钱、符纸 → 局外升级 → 下一关。

## 4. 一局流程
菜单 → 选关 → 战斗（可暂停）→ 结算 → 奖励展示 → 局外养成。胜利条件是击败本关 Boss，结界归零即失败。详见第 1 节。

## 6. 不做
改变局内玩法的局外系统（法器、角色、皮肤）、付费货币、体力、联网、排行榜、云存档。
